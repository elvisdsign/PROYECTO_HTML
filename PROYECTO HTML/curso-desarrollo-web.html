Desarrollo web desde cero

Este curso te introduce al desarrollo web y a las habilidades necesarias para crear sitios y aplicaciones. Aprenderás a organizar una página con HTML y conocerás las tecnologías que forman parte del desarrollo full stack.

Qué aprenderás

  • La estructura y los elementos semánticos de documentos HTML.
  • Los fundamentos del desarrollo de páginas y aplicaciones web.
  • Cómo continuar tu aprendizaje con proyectos prácticos.
